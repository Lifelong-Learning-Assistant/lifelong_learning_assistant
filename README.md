# Lifelong Learning Assistant для Deep Learning

> **Идея**: Создать персонализированного ИИ-ассистента для непрерывного обучения.

## 🎯 Цель проекта

Создать интеллектуального ассистента, который интегрирует личную базу знаний (Obsidian), внешние источники (учебники, статьи, новости) и помогает:

- **Непрерывно учиться** и адаптировать объяснения под текущий уровень понимания
- **Поддерживать актуальность** знаний через отслеживание трендов
- **Готовиться к собеседованиям** с контекстуальными ссылками
- **Вести персональную базу знаний** с автоматической поддержкой в актуальном состоянии

## 🧠 Архитектура системы

### Ключевые компоненты

| Компонент | Источник | Основные функции |
|-----------|----------|------------------|
| **Новостной модуль** | Telegram-каналы (API) | Отслеживание трендов DL/ML, индексация с цитированием |
| **База знаний** | Obsidian (Markdown + граф) | Персональный контекст: "Что я знаю?", "Как понимал раньше?" |
| **Учебный модуль** | Яндекс ML, книги, статьи | Глубокие объяснения с адаптацией под уровень |
| **Репетиторский агент** | Комбинация источников | Динамическое упрощение/усложнение объяснений |
| **Собеседовательный модуль** | Конспекты, LeetCode | Подготовка к интервью: структурированные ответы |
| **Книжный RAG** | Выбранные книги | Детальные ответы с указанием глав/страниц |

### Дополнительная функциональность

- **📝 Управление заметками**: Создание карточек интервального повторения, тематических шпаргалок
- **🧩 Генерация квизов**: Динамические тесты для активного воспроизведения знаний
- **🎭 Симуляция собеседований**: МООК-собеседования с обратной связью
- **🔍 Мульти-поиск**: Ответы с опорой на источники (Obsidian/Учебник/Книги/Интернет)
- **📡 Telegram-интеграция**: Анализ новостей, категоризация контента, предложения для карточек

## 🛠 Техническая реализация

- **Frontend**: Streamlit (основной), Telegram-бот (альтернатива)
- **Backend**: FastAPI/LangChain/LlamaIndex для оркестрации
- **Хранилище**: Chroma/FAISS/Qdrant (локально) с раздельными коллекциями
- **Модель**: Локальная (Ollama, LM Studio, vLLM) для приватности
- **Развертывание**: Docker-контейнеры с Web-UI интерфейсом
- **Obsidian**: Парсинг `.md` файлов, извлечение связей (`obsidian-export`/`dataview` API)

## 📋 Примеры использования

### Обучение и объяснения
1. **"Что нового в LLM за последнюю неделю?"**  
   → Поиск в Telegram-каналах, 3 ключевые новости с цитатами

2. **"Объясни attention mechanism для начинающего"**  
   → Учебник Яндекса + книга Goodfellow, упрощенный ответ с ссылками

3. **"Как я понимал attention в своих заметках?"**  
   → Поиск в Obsidian, показ прошлых записей + предложения обновления

### Подготовка к собеседованиям
4. **"Ответ на вопрос 'fine-tuning LLM' для стартапа"**  
   → Структурированный ответ (определение→методы→примеры→pitfalls)

5. **"Симуляция собеседования по CV/NLP"**  
   → Пошаговая схема: алгоритмы → классический МЛ → спецобласть

### Сравнение и интеграция
6. **"Сравни моё понимание diffusion models с учебником"**  
   → Сопоставление заметок и источника, выделение расхождений

## 💡 Уникальные преимущества

**Это не просто RAG-чат, а интеллектуальный компаньон для профессионального роста**, который:
- Знает **твои знания** (через Obsidian)
- Знает **глобальные знания** (учебники, новости)  
- Умеет **объяснять и готовить к собеседованиям**
- **Отслеживает тренды** — всё в одном месте

### Образовательный фокус
- Алгоритмы интервального повторения для ключевых идей
- Автоматическая генерация квизов и карточек
- Активное воспроизведение знаний с динамическими вопросами
- Интеграция с образовательными платформами (возможность open source/Яндекс.Практикум)

## 📚 Модульная структура

Проект объединяет отдельные компоненты:
- **Knowledge Assistant** - управление базой знаний
- **Ассистент для собеседований** - подготовка к интервью
- **AI репетитор** - объяснения и адаптация
- **News Assistant AI** - отслеживание трендов
- **Поисковик по Яндекс МЛ** - работа с учебниками
- **Book RAG** - работа с книгами

**Цель курса**: Реализация MVP с 1-2 ключевыми компонентами.
